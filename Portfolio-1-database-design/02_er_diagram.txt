==========================================================================================
2. ENTITY RELATIONSHIP DIAGRAM (ERD)
==========================================================================================

Evidence for Portfolio 1: Database Design and Modelling, Hospital Management System (Miva
Hospital), PostgreSQL.

The ER diagram presents the five tables, their attributes, primary keys, foreign keys and
the relationships between them, shown as connector lines.

See image file: 02_er_diagram.png (in this folder)

Diagram note: PK indicates a primary key; FK indicates a foreign key.

DATA TYPES SHOWN IN THE DIAGRAM
-------------------------------

The image file 02_er_diagram.png labels some columns with SQL Server types. In the
PostgreSQL schema these columns use the following types:

+---------------------------------+---------------------+-----------------+
| Column                          | Type shown in image | PostgreSQL type |
+=================================+=====================+=================+
| Appointments.appointment_date   | datetime2           | TIMESTAMP(0)    |
+---------------------------------+---------------------+-----------------+
| Appointments.diagnosis          | varchar(max)        | TEXT            |
+---------------------------------+---------------------+-----------------+
| Prescriptions.prescription_date | datetime2           | TIMESTAMP(0)    |
+---------------------------------+---------------------+-----------------+
| Laboratory_Records.test_result  | varchar(max)        | TEXT            |
+---------------------------------+---------------------+-----------------+
| Laboratory_Records.test_date    | datetime2           | TIMESTAMP(0)    |
+---------------------------------+---------------------+-----------------+

The full list of attributes and types is in 03_relational_schema.txt.

RELATIONSHIP EXPLANATION
------------------------

+----------------------+----------------+-----------------------------------------------+
| Relationship         | Cardinality    | Explanation                                   |
+======================+================+===============================================+
| Patients -           | One-to-Many    | One patient can book multiple appointments,   |
| Appointments         |                | but each appointment belongs to one patient.  |
+----------------------+----------------+-----------------------------------------------+
| Doctors -            | One-to-Many    | One doctor can attend multiple appointments,  |
| Appointments         |                | but each appointment is assigned to one       |
|                      |                | doctor.                                       |
+----------------------+----------------+-----------------------------------------------+
| Patients -           | One-to-Many    | One patient can receive multiple              |
| Prescriptions        |                | prescriptions.                                |
+----------------------+----------------+-----------------------------------------------+
| Doctors -            | One-to-Many    | One doctor can prescribe multiple             |
| Prescriptions        |                | medications.                                  |
+----------------------+----------------+-----------------------------------------------+
| Appointments -       | Optional       | A prescription may be associated with an      |
| Prescriptions        | One-to-Many    | appointment; an appointment can have multiple |
|                      |                | prescriptions.                                |
+----------------------+----------------+-----------------------------------------------+
| Patients -           | One-to-Many    | One patient can have multiple laboratory      |
| Laboratory Records   |                | records.                                      |
+----------------------+----------------+-----------------------------------------------+
| Doctors - Laboratory | Optional       | A doctor may be associated with multiple      |
| Records              | One-to-Many    | laboratory records.                           |
+----------------------+----------------+-----------------------------------------------+
| Appointments -       | Optional       | A laboratory record may be associated with an |
| Laboratory Records   | One-to-Many    | appointment.                                  |
+----------------------+----------------+-----------------------------------------------+
